PROMPT · 5 PARTS

‘5요소’는 외울 단어가 아니라 채우는 5칸입니다

1 역할AI가 어떤 담당자처럼 일할지“당신은 채용공고를 쓰는 HR 담당자입니다.”
2 맥락누구를 위해 왜 만드는지“데이터 분석가 채용을 위해 지원자가 이해하기 쉬운 공고를 만듭니다.”
3 제약반드시 지키거나 하지 말아야 할 것“성별·연령 암시 표현은 쓰지 말고, 확인되지 않은 복지는 만들지 마세요.”
4 출력 형식결과를 어떤 모양으로 받을지“직무 소개·주요 업무·필수 요건·우대 요건·지원 안내 순서의 표로 작성하세요.”
5 예시원하는 수준과 말투를 보여주는 샘플“짧은 문장, 친절하지만 과장하지 않는 톤”

FAQ

자주 묻는 질문

GPT나 제미나이에 질문만 해봤는데 참여할 수 있나요?

가능합니다. 전문용어를 전제로 하지 않고 완성 예시를 보며 한 칸씩 따라가는 방식으로 시작합니다.

회사 노트북에서 외부 AI나 API 접속이 막히면 어떻게 하나요?

교육 1주 전 접속점검에서 확인하고, 당일에는 준비된 복제본 또는 강사 화면 따라 검수 경로로 전환합니다. 설정 제한 때문에 핵심 Output을 놓치지 않도록 설계했습니다.

n8n과 API를 반드시 직접 연결해야 하나요?

아닙니다. D3-M3의 직접 연결은 선택 심화입니다. 기본 과정은 준비된 워크플로우를 복제해 흐름을 이해하고 테스트하는 데 집중합니다.

실제 지원자나 구성원 데이터를 사용하나요?

사용하지 않습니다. 전 실습은 가상 지원서·더미 설문·가상 구성원 정보로 진행합니다.

수료는 기술 설정 성공 여부로 결정되나요?

아닙니다. 안전한 결과물을 완성하고 근거·검수 방법을 설명할 수 있는지를 봅니다. 보안 제한이 있으면 대체 산출물을 인정합니다.
